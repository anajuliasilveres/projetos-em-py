# projetos-em-py

Repositório criado para guardar meus desafios e projetos em Python enquanto pratico e evoluo na programação.

## Sobre este repositório

Este repositório acompanha minha evolução no aprendizado de Python. A ideia é resolver desafios práticos, do mais simples ao mais complexo, organizando tudo por tema conforme eu avanço nos estudos.

A trilha de estudos está organizada assim:

1. **Condicionais** — primeiros exercícios usando `if`, `elif` e `else`.
2. **Repetições** — exercícios com laços `for` e `while`.
3. **Listas** — manipulação e organização de dados com listas.
4. **Funções** — reorganizando a lógica dos exercícios em funções reutilizáveis.
5. **Desafios maiores** — projetos mais completos, juntando tudo o que foi aprendido.

## Estrutura

Cada pasta representa um desafio e contém um arquivo `main.py` onde o código será desenvolvido.
